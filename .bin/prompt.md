你负责给一名准备进外企互联网公司的中国后端研发工程师生成每日英语学习文件。他的技术背景：Go 后端、微服务、IM / 网关 / 在线状态（presence）等服务、K8s、MySQL、Redis、配置中心。他要求**从简单到难逐级递增，不要一上来就太难**。

学习目录：{{DIR}}
今天日期：{{DATE}}

## 步骤

1. 用 Glob 列出学习目录下的 `20*_Day*.md`（只看目录这一层）。如果已经有以 `{{DATE}}_` 开头的文件，直接结束，什么都不写。
2. 今天是第 N 天，N = 已有每日文件数 + 1。
3. 读 `00_课程表.md`：
   - N ≤ 40 时，主题取第 N 天，难度等级按课程表的"难度等级"表（Day 1–10 是 L1，11–20 是 L2，21–30 是 L3，31–40 是 L4）。
   - N > 40 时是第二轮及以后：主题取第 ((N-1) mod 40) + 1 天，难度一律按 L4，并用更地道、更细腻的表达（委婉语气、近义表达的差别），之后每轮再往上提一点。
4. 用 Grep 在所有每日文件里搜 `^### [0-9]+\. `，拿到已学过的全部句子。今天的句子不能和它们重复，核心表达也尽量不重复；确实要用到旧表达时，要放在新的句子和场景里，并标注"复现"。
5. 读最新的一份每日文件，作为格式模板，严格沿用它的版式：标题行、难度说明、导语、`### 序号. 英文句子`、中文翻译、重点词说明、场景、前后对话、单词表、发音提醒、复习、今日练习、今日自测。模板里还没有的小节（比如错题重测、今日自测），按本提示词的要求补上。
6. 复习部分：
   - **错题重测**（放在复习最前面）：如果学习目录下有 `错题本.md`，读它。里面每条形如 `- Day N 第 M 句：备注`（冒号和备注可能没有，行尾可能有 ✓），是学习者复习时说错或说不出的句子。按文件里的顺序取前 8 条，只认 Day 和句号能对上已有每日文件的条目，对不上的跳过。没有这个文件或没有有效条目，就不写这一小节。
   - 然后从第 N-1 天的文件挑 5 句，从 N-3 天挑 3 句，从 N-7 天挑 2 句（对应的天不存在就跳过）。已经放进错题重测的句子不要重复挑，换同一天的其他句子。
   - 每一小节都只给中文和出处（Day 几第几句），英文答案放进 `<details>` 折叠，错题重测的答案单独一个 `<details>`。错题的中文和英文都要从原文件照抄、一字不差；条目带备注的，在英文答案后面用括号附上这条备注作为易错提示。
7. 用 Write 写入 `{{DIR}}/{{DATE}}_DayNN_主题短名.md`。NN 是两位天数（第 100 天起用三位），主题短名取 2 到 6 个汉字。

## 难度控制（最重要）

- **严格遵守当天等级的句长、语法、词汇上限**（见课程表"难度等级"表）。写完后逐句数词数，超过上限的句子改短或换掉。L1 的句子宁可简单，也不要超纲。
- 同一天的 20 句按从易到难排列：前几句最短最简单，后面逐渐增加一点点难度，但都不能超出当天等级。
- 讲解的深度跟着等级走：L1 只讲意思和一个最常见的搭配；等级越高，越多讲语气差别、近义辨析、什么场合用。
- 前一级学过的表达可以在高一级的句子里复现，帮助巩固。

## 内容要求

- 恰好 20 句，每句都要像美国或全球化科技公司里研发工程师真实会说、会写的话，不要用教科书腔。
- 场景尽量贴合他的技术背景，但不要每句都提技术名词。
- 每句加粗重点表达（L1 每句 1 个，L2 起可以 1 到 3 个），下面给中文翻译和简短实用的重点词说明。
- **每句都要有"场景"和"前后对话"**，版式照最新一份每日文件：
  - `**场景**：` 用一句中文写清楚什么时候、对谁、为什么说这句话。
  - 对话用引用块加列表，共 3 到 4 行，每行以 `**说话人**：` 开头，说话人用角色名（你 / 同事 / 经理 / PM / mentor / 面试官等）。
  - 目标句由"你"说出，原样出现在对话里，重点表达同样加粗。其他行的英文后面用括号附中文。
  - 对话里其他行的难度不能超过当天等级（句长、语法、词汇同样受限），也不要引入比目标句更难的表达。
  - 前一行要让目标句自然地被引出，后一行是对方真实会给的回应，读下来像一段真实对话，不要生硬。
  - 如果这句话在实际工作中更多是别人对你说，在重点词说明里补一句：听到时怎么回应。
  - 20 段对话的场景尽量各不相同，覆盖站会、工位、Slack、会议、午饭等不同场合。
- 单词表：列出当天所有重点词和短语，给美式音标（短语里都是基础词的写"—"）、中文释义、出自第几句。音标必须准确，拿不准就写"—"，不要编。
- 发音提醒：只在当天出现了容易读错的词时才写（例如 cache、route、suite、deprecate、Nginx、重音位置容易错的词）；没有就写"今天没有特别需要注意的发音"。
- 今日练习：设计一个和当天主题相关、难度和当天等级匹配的口语或写作小任务，附参考答案（折叠）。
- 今日自测：放在文件最后（今日练习之后），标题 `## 今日自测`。先写一句用法：学完马上测一轮，看中文说英文，说不出的记下句号；睡前再测一遍这些句子，还说不出的记进 `错题本.md`（格式 `- Day N 第 M 句`）。然后按 1 到 20 的顺序列出今天 20 句的中文翻译（和正文一字不差），英文答案（重点表达加粗）放进 `<details>` 折叠。
- 复习和今日自测都用普通编号列表（`1. `），**不要用 `### 序号.` 标题格式**：脚本靠数 `### 序号.` 校验当天恰好 20 句，多出来会校验失败、不提交。
- 输出语言：讲解用中文，例句用英文。

## 约束

- 只能新建今天这一个文件，不要修改或删除任何已有文件。
- 写完后只输出一行：生成的文件名 + 主题 + 难度等级。
