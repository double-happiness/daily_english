# 微信推送配置

`generate.sh` 每天生成 20 句并推送到 GitHub 成功后，会通过 [Server酱](https://sct.ftqq.com) 把当天的文件发到绑定的微信。

本文是在**跑定时任务的那台电脑**上的配置步骤，按顺序执行即可。

> sendkey 不能提交到仓库（仓库是公开的），下面用 `<你的SendKey>` 占位，执行时替换成 `SCT` 开头的那串。

## 第 1 步：确认现状

```bash
ls ~/研发英语/.bin/generate.sh
launchctl list | grep dev-english-daily
```

- 两条都有输出：已安装，继续第 2 步
- 任一条没输出：先做文末「附：从零安装」，再回到第 2 步

## 第 2 步：拉取最新脚本

```bash
cd ~/研发英语 && git pull
grep -c send_wechat .bin/generate.sh   # 输出 2 表示已是新版本
```

## 第 3 步：写入 sendkey

```bash
mkdir -p ~/.config/daily_english
echo '<你的SendKey>' > ~/.config/daily_english/serverchan_key
chmod 600 ~/.config/daily_english/serverchan_key
```

sendkey 获取：sct.ftqq.com 微信扫码登录 →「SendKey」页面复制。

## 第 4 步：确认 git 能推送

GitHub 推送失败时不会发微信，所以这一步必须通过：

```bash
cd ~/研发英语 && git push --dry-run origin main
```

报 403 / denied 时改用 SSH（前提是这台电脑的 SSH key 已加到仓库所有者账号）：

```bash
git remote set-url origin git@github.com:double-happiness/daily_english.git
ssh -T git@github.com   # 显示 Hi double-happiness! 即可
```

## 第 5 步：验证（二选一）

- **跑一次，确认微信能收到**（当天文件已推送过时，会直接发一条微信）：

  ```bash
  bash ~/研发英语/.bin/generate.sh; tail -5 ~/研发英语/.logs/$(date +%F).log
  ```

- **当天已在别的电脑发过，不想重复收**：

  ```bash
  mkdir -p ~/研发英语/.logs && touch ~/研发英语/.logs/$(date +%F).wechat-sent
  ```

## 推送逻辑

1. 07:00、登录时或每 30 分钟的重试触发 → 生成当天文件 → 校验 20 句 → 提交 → 推送 GitHub
2. **GitHub 推送成功后**发微信：标题 `研发英语 DayNN 主题`，正文为当天完整 markdown
3. 发送成功写标记 `.logs/<日期>.wechat-sent`，同一天重复触发不会重复发
4. 发送失败只记日志，不写标记，下次触发自动重试；不影响提交和推送
5. 没配 sendkey 时跳过发送，只记一条日志
6. `NO_NOTIFY=1` 时同时关闭桌面通知和微信推送（测试用）

## 每天怎么检查

```bash
tail ~/研发英语/.logs/$(date +%F).log
```

| 日志内容 | 含义 |
|---|---|
| `pushed 1 commit(s)` + `wechat pushed` | 全部成功 |
| `warn: wechat push ...` | GitHub 已推送，微信没发出去（后面附原因），下次触发重试 |
| `warn: push failed` / `fetch failed` | GitHub 推送失败，所以没发微信 |
| `warn: no Server酱 sendkey` | 第 3 步没做 |

Server酱 免费版每天限 5 条，每天 1 条够用。

## 附：从零安装

仅在第 1 步检查不通过时执行。已安装的电脑不要覆盖原有 plist。

```bash
# 1. 克隆到脚本要求的路径
git clone git@github.com:double-happiness/daily_english.git ~/研发英语

# 2. 确认 claude 在脚本要求的位置（生成内容需要）
ls ~/.local/bin/claude

# 3. 创建定时任务：每天 07:00 执行，登录时也执行一次（补跑），之后每 30 分钟重试（当天已完成即退出）
cat > ~/Library/LaunchAgents/local.dev-english-daily.plist <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>local.dev-english-daily</string>
  <key>ProgramArguments</key>
  <array><string>/bin/bash</string><string>$HOME/研发英语/.bin/generate.sh</string></array>
  <key>StartCalendarInterval</key>
  <dict><key>Hour</key><integer>7</integer><key>Minute</key><integer>0</integer></dict>
  <key>RunAtLoad</key><true/>
  <key>StartInterval</key><integer>1800</integer>
  <key>EnvironmentVariables</key>
  <dict><key>PATH</key><string>/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:$HOME/.local/bin</string></dict>
</dict>
</plist>
EOF
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.dev-english-daily.plist
```

停用 / 恢复：

```bash
launchctl bootout gui/$(id -u)/local.dev-english-daily
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.dev-english-daily.plist
```
